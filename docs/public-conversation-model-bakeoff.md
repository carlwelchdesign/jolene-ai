# Public conversation model bakeoff — 2026-09-01

## Decision

Use `gpt-5.6-terra` for the public Jolene conversational MVP.

Both `gpt-5.6-terra` and `gpt-5.6-sol` passed the eight-case live
conversation-only contract with zero canned-copy matches. Terra was faster in
this sample, produced the stronger overall balance of warmth and compact
situational wit, and cost roughly half as much at current text-token prices.

This was a targeted MVP bakeoff, not a claim that Terra is universally better.
The selected cases covered absurd capability mismatches, a plausible unsupported
technical claim, a real legal boundary, greeting, check-in, private-material
refusal, and conflicting sources.

## Measured result

| Contract accepted | 8/8 | 8/8 |

| Mean latency | 2,071 ms | 2,625 ms |
| p95 latency | 2,498 ms | 4,425 ms |
| Input tokens, eight turns | 14,906 | 14,906 |
| Output tokens, eight turns | 725 | 772 |
| Estimated cost, eight turns | $0.0385 | $0.0751 |

Cost uses the official prices reviewed on 2026-09-01: Terra at $2 per million
input tokens and $12 per million output tokens; Sol at $4 and $20. Pricing can
change and must be refreshed before a later cost decision.

## Exact regression prompt after style calibration

Prompt:

> I need Carl to perform brain surgery

Accepted Terra response from the final one-case check:

> No—there’s nothing here to support sending Carl anywhere near an operating
> room; that would be a mighty bad place for improvisation. For brain surgery,
> please contact a qualified neurosurgeon or medical service. I can help with
> questions about Carl’s public portfolio work instead.

This response was generated by the model, not selected from a canned-response
table. The runtime no longer contains a brain-surgery answer. The contract keeps
zero claims and zero citations for this turn, blocks new positive or negative
qualification claims about Carl, and falls back to fixed safe copy only when the
provider, budget, or validator fails.

## Voice and rights boundary

The prompt uses the existing interview-research abstraction: compact situational
wit, playful reversal, self-aware understatement, warmth, candor, and a quick
return to practical substance. It does not ask the model to claim a real identity,
copy interview wording, reproduce catchphrases or dialect, or imitate a voice.
